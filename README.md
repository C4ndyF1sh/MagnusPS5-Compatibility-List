# MagnusPS5-Compatibility-List

Tested devices:
iPad Air 5th Gen (M1) | iPadOS 26.6.x (does NOT work on 27.x with free dev acc)
iPad Mini 7th Gen (A17 Pro) | iPadOS 26.6 (should work on 27.x)

Requirements:
- SideStore
- StikDebug
- GetMoreRam
- 8gb Ram or more (<=6gb Ram devices have not been tested)
- If you did all this and it still crashes you may need a paid developer account

MagnusPS5: https://github.com/hernan0078/MagnusPS5
